# Vinyl Player
1. Open this folder in Android Studio (Koala or newer), let Gradle sync.
2. Run on your phone (USB debugging) or build an APK: Build > Build APK(s).
3. Open the app, tap "Open settings", enable Vinyl Player under notification access.
4. Play a song in Spotify / YouTube Music and come back to the app.
Lyrics come from LRCLIB (free, no key). If a song has no synced lyrics, the lyric area stays empty.
